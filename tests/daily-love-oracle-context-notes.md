# DAILY / Oracle context selector verification

- DAILY love statuses are multi-select: 솔로, 썸, 짝사랑, 재회, 연애중, 기혼.
- 솔로 explicitly includes 소개팅, 새 인연, 새로운 만남.
- DAILY prompt requires 대인관계 separately and one independent subsection per selected love status.
- Message Oracle keeps AUTO as the default and preserves the existing manual context override chips.
- Timing Oracle keeps AUTO as the default and offers an optional manual sector override.
- Timing sector context is added to both support-reading prompts and standalone Timing AI requests.
- Vercel preview for the branch reached READY after the final contract-test commit.
